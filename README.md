# 이의 있음!

형법 기출 OX 법정 배틀 게임. 혼자 공부할 때 쓰려고 만든 PWA(홈 화면에 설치하는 웹앱)입니다.

## 폰에 설치하기
- **아이폰**: Safari로 사이트 주소 열기 → 공유 버튼 → "홈 화면에 추가"
- **안드로이드**: Chrome으로 사이트 주소 열기 → 메뉴(⋮) → "홈 화면에 추가" 또는 "앱 설치"

한 번 연 뒤에는 인터넷 없이도 실행됩니다.

## 기록
- 기록은 각 기기 안에 저장됩니다.
- 처음 실행할 때는 `seed-save.json`(claude.ai 버전에서 옮겨 온 기록)을 불러옵니다.
- 기기를 바꾸거나 두 폰에서 이어서 하려면 홈 → 기록·규칙 페이지에서 **기록 백업**으로 파일을 만들고, 다른 기기에서 **기록 불러오기**로 그 파일을 고르세요.

## 수정한 뒤
게임 파일을 바꿨다면 오프라인 캐시 목록을 다시 만듭니다.

```bash
python3 tools/build-sw.py
```

## 폴더 구성
- `index.html`: 게임 전체 (화면, 스타일, 로직)
- `data.json`: 문제·판례 데이터
- `a/`: 캐릭터·배경 이미지, 효과음
- `f/`: 글꼴
- `icons/`, `manifest.webmanifest`, `sw.js`: 앱 설치와 오프라인 실행
